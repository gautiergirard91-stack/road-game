🎯 Où viser ? Le « 0 ms »

Le 0 ms = la ligne blanche exactement sous la roue que tu tapes (essieu AV = Z / zone gauche, roues AR = S / zone droite). La fenêtre est symétrique : un tap jusqu'à 45 ms avant la ligne est aussi PARFAIT. Le « tic » audio joue exactement à 0 ms. Ta stat ⚡ = l'écart moyen en ms à ce moment : plus elle est proche de 0, mieux tu classes.
